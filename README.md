## 中文

我关注软硬件系统如何从原型走到可复现、可交接的工程：从传感器数据采集、固件状态机和串口通信，到桌面控制界面、诊断日志与验收文档。

| 方向 | 技术与实践 |
| --- | --- |
| 嵌入式控制 | STM32、ESP32、C、MicroPython；外设接入、通信协议、控制状态机 |
| 桌面工具 | Qt、C++、CMake；任务编排、设备配置与故障诊断 |
| 边缘视觉 | K230、CanMV；图像观测与串口联动 |
| 工程验证 | 独立构建、分层测试、实车验收与交接文档 |

**工程习惯：** 先记录现象，再定位故障；分别说明软件测试能证明什么、现场还需要验证什么。

## English

I work on turning hardware–software prototypes into systems that others can reproduce and maintain, from sensor interfaces, firmware state machines, and serial protocols to desktop controls, diagnostic logs, and acceptance documentation.

| Focus | Technologies and practice |
| --- | --- |
| Embedded control | STM32, ESP32, C, MicroPython; peripheral interfaces, protocols, and state machines |
| Desktop tooling | Qt, C++, CMake; task orchestration, device configuration, and diagnostics |
| Edge vision | K230, CanMV; visual observations and serial integration |
| Engineering verification | Independent builds, layered tests, physical acceptance, and handover documentation |

**Engineering practice:** Record the symptom before changing the system, and keep software evidence separate from what still needs to be verified on hardware.
